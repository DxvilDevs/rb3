RoBlast site

Files:
- index.html: landing page
- games.html: full games catalogue page
- styles.css: shared styling
- script.js: navigation, hero rotation and reveal motion
- favicon.svg: RoBlast favicon/mark

The two Roblox game artwork URLs are hotlinked from Roblox's CDN. The buttons link directly to the supplied Roblox game pages.

To publish on GitHub Pages, upload these files to the repository root and enable Pages for the main branch.


Live stats use the Roblox endpoints and fallback proxy strategy mirrored from the supplied Boxed Up Games project, including place-to-universe resolution, game detail, and favourites-count endpoints. The hero uses a custom vector background (hero-visual.svg) rather than the previously supplied hero background image.
